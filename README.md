# Polyglot Studio

แอปเว็บแบบ static ไม่มีขั้นตอน build ประกอบด้วยสตูดิโอสร้างสื่อและวาดรูป (ไม่มีฟังก์ชันคำศัพท์แล้ว)

## วิธีเปิด

1. แตก ZIP ไปยังโฟลเดอร์ที่ต้องการ
2. เปิดเทอร์มินัลในโฟลเดอร์นั้น แล้วรัน `python3 -m http.server 8000` (Windows ใช้ `py -m http.server 8000`)
3. เปิด `http://localhost:8000` ในเบราว์เซอร์

ควรเปิดผ่าน local server หรือ HTTPS เพื่อให้ service worker และการติดตั้ง PWA ทำงานได้

## ฟีเจอร์

- **ใบงานคัดลายมือ**: กรอกข้อความเองแล้วสร้างใบงาน ปรับรูปแบบ หัว-ท้ายกระดาษ ขอบกระดาษ สี โลโก้ และพิมพ์/ส่งออกได้ (ไฟล์ `worksheet-extras.js`)
- **ตารางคัดทีละตัว (โหมด ▦ ในใบงาน)**: 1 บรรทัดคำ = 1 แถว มีป้ายซ้าย ช่องตัวอย่างสีชมพู ช่องลากตามรอยจางลงทีละช่อง และช่องเขียนเอง (มีรูปแบบตารางคำศัพท์เพิ่ม: คัดคำศัพท์, ดู–ปิด–เขียน–ตรวจ, ดูคำแปลแล้วเขียนคำ, สมุดจดคำศัพท์) เลือกช่องเส้นบรรทัด/米字格/十字 ได้ มีชุดสำเร็จรูป ไทย อังกฤษ จีน ญี่ปุ่น เกาหลี และตัวสร้างผสมพยัญชนะ+สระไทย
- **โหมดจัดวางอิสระ (ใบงาน)**: เลือก “อัตโนมัติ / อิสระ” แล้วลากบล็อกไปวางเองบนกระดาษ จำตำแหน่งไว้ มีสีพื้นหลังกระดาษ คลังคำศัพท์ไทย/จีน/ญี่ปุ่นเพิ่ม และแบบร่างที่เก็บทั้งใบงาน (ไฟล์ `worksheet-free.js`)
- **ตัวอักษรลูกโป่ง**: สร้างภาพและชุดสติกเกอร์จากข้อความ เลือกรูปทรงลูกโป่งใหญ่ (กลม/เมฆ/หัวใจ/ดาว) ใส่โค้ดสี Hex/RGB ได้ทุกช่องสี และส่งออก PNG โปร่งใสตัดขอบพอดี (ไฟล์ `balloon-plus.js`, `pg-color-fields.js`)
- **วาดรูป (SkillHub)**: ผืนผ้าของฉัน (โฟลเดอร์ ค้นหา เรียงลำดับ ปักหมุด ส่งออก PNG แชร์ ลบ) และสตูดิโอวาดรูป (`draw.html`, `draw-studio.html`)
- **สตูดิโอวาดรูป — สีที่ชอบและไม้บรรทัด**: แถว "⭐ เก็บสีนี้" เก็บสีโปรดได้สูงสุด 24 สี (แตะเพื่อใช้ กดค้างเพื่อลบ เก็บที่คีย์ `sh4fav`) และปุ่ม "ไม้บรรทัด" ในแถบเครื่องมือ เริ่มลากเส้นใกล้ขอบแถบแล้วเส้นจะตรงตามไม้บรรทัด ลากวงกลมสีฟ้าเพื่อหมุน/ปรับความยาว (ล็อกมุมทุก 15° เมื่อใกล้) วงกลมสีเหลืองเพื่อย้าย จำตำแหน่งไว้ที่ `sh4ru`
- **ฝึกพิมพ์ดีด — ทบทวนคำที่ผิดบ่อยและเลือกหมวด**: ระบบจำคำที่พิมพ์พลาดต่อภาษา (`typing_weak_words`) โหมด "🔁 ทบทวนคำผิด" สุ่มคำเหล่านั้นมาให้ซ้ำ พิมพ์ถูกโดยไม่พลาดแล้วจำนวนจะลด ดูและลบรายการได้ที่ "คำที่พิมพ์ผิดบ่อย" ส่วน "🗂️ เลือกหมวดหมู่" ปักบทหรือหมวดคำที่ต้องการฝึกซ้ำได้ (สลับภาษา/ระดับเพื่อยกเลิก) ทั้งสองรวมอยู่ในไฟล์สำรองของฝึกพิมพ์
- **เครื่องมือเสริม (`extras.html`)**: ตารางผสมตัวอักษรเกาหลี (พยัญชนะต้น × สระ × ตัวสะกด พร้อมคำอ่านและเสียง), ตารางเทียบฮิรางานะ/คาตากานะ/อักษรจีนต้นทางพร้อมพินอิน (ซ่อนคอลัมน์เพื่อทายได้), เครื่องฟังเสียงออกเสียง 5 ภาษา (ใช้เสียงของเบราว์เซอร์/ระบบ ปรับความเร็ว ระดับเสียง และแยกเป็นคำ) และหน้าตั้งค่าแอป (ขนาดตัวอักษร เสียงอ่านเริ่มต้น ธีมของสตูดิโอวาดรูป/ฝึกพิมพ์ ดูพื้นที่เก็บข้อมูล ล้างแคช ลบข้อมูลฝึกพิมพ์)
- PWA พร้อม service worker สำหรับแคชแอป

## ออฟไลน์

ไฟล์ของแอปและ html2canvas ถูกแคชโดย service worker เสียงอ่านของเครื่องมือเสริมใช้เสียงที่ติดตั้งในอุปกรณ์ (ออฟไลน์ได้ถ้าเครื่องมีเสียงภาษานั้น) ส่วนตัวสร้าง QR (qrcode-generator) ยังโหลดจาก cdnjs ตอนติดตั้ง ควรเปิดแอปแบบออนไลน์อย่างน้อยหนึ่งครั้งก่อนใช้ออฟไลน์

## หมายเหตุ

ฟังก์ชันคำศัพท์ทั้งหมด (คลังคำศัพท์ ทบทวน แฟลชการ์ด แบบทดสอบ ฝึกอ่านด้วย AI เติมข้อมูล ตรวจคุณภาพ พจนานุกรม สถิติ และข้อมูลศัพท์ที่ฝังมา) ถูกนำออกแล้ว หากเบราว์เซอร์เคยใช้แอปเวอร์ชันเก่า ข้อมูลเดิมจะยังค้างอยู่ใน localStorage คีย์ `pg:v1` ลบทิ้งได้เองที่ DevTools → Application → Local Storage
