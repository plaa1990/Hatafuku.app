# Polyglot Studio

แอปเว็บแบบ static ไม่มีขั้นตอน build และเก็บคลังคำศัพท์ไว้ใน browser เครื่องที่เปิดใช้งาน

## วิธีเปิด

1. แตก ZIP ไปยังโฟลเดอร์ที่ต้องการ
2. เปิดเทอร์มินัลในโฟลเดอร์นั้น แล้วรัน `python3 -m http.server 8000`
   - Windows ใช้ `py -m http.server 8000` ได้
3. เปิด `http://localhost:8000` ในเบราว์เซอร์

ควรเปิดผ่าน local server แทนการเปิด `index.html` โดยตรง เพื่อให้ manifest และ service worker ทำงานได้ แอปบางส่วนใช้ฟอนต์และไลบรารีจาก CDN จึงต้องเชื่อมต่ออินเทอร์เน็ตสำหรับฟีเจอร์เหล่านั้น

## ฟีเจอร์ที่เพิ่ม

- คลังคำศัพท์: เลือกระดับ CEFR A1–C2 หรือกำหนดระดับเอง, สถานะงาน, แท็กสี, โน้ต, วันที่สร้าง/แก้ไข, กรองตามระดับ, ย้ายลำดับ และทำสำเนาคำ
- ใบงาน: สีตัวอักษร/เส้น, เทมเพลตเว้นช่อง, โลโก้และที่อยู่ซ้ำทุกหน้า, กรอบการ์ด, ช่องคะแนน, สุ่มคำ, ขอบกระดาษรายด้าน, คำแนวตั้ง และซ่อนคำชั่วคราว
- สติกเกอร์: ตัดบรรทัดอัตโนมัติ, ตัวเอียง, พรีวิวแบบแชต และชื่อ/คำอธิบาย/แท็กในไฟล์ ZIP
- มือถือ: เปิดเครื่องมือคัดลายมือและสติกเกอร์แบบเต็มจอ พร้อมจัดตัวเลือกเป็นกลุ่มพับ/ขยาย แล้วกลับสู่หน้าแอปได้ทันที

## ข้อมูลและสำรอง

ข้อมูลคำศัพท์บันทึกใน local storage ของเบราว์เซอร์นั้น ใช้ปุ่ม Export backup เพื่อเก็บสำเนา JSON; Export CSV มีระดับ สถานะ โน้ต แท็กสี และวันที่สร้าง/แก้ไขรวมอยู่ด้วย
