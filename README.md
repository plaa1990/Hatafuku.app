# Polyglot Studio — ชุดข้อมูลแก้ไขแล้ว

แอปเว็บแบบ static ไม่มีขั้นตอน build คลังคำศัพท์ชุดที่แก้ไขแล้วฝังมากับแอปและใช้งานออฟไลน์ได้ ส่วนตารางทบทวนและการตั้งค่าจะเก็บใน local storage ของเบราว์เซอร์

## วิธีเปิด

1. แตก ZIP ไปยังโฟลเดอร์ที่ต้องการ
2. เปิดเทอร์มินัลในโฟลเดอร์นั้น แล้วรัน `python3 -m http.server 8000` (Windows ใช้ `py -m http.server 8000`)
3. เปิด `http://localhost:8000` ในเบราว์เซอร์

ควรเปิดผ่าน local server หรือ HTTPS เพื่อให้ service worker และการติดตั้ง PWA ทำงานได้

## ข้อมูลศัพท์ที่รวมมา

- มีคำศัพท์ที่ผ่านการรวมรายการซ้ำแล้ว 4938 รายการ ฝังใน `polyglot-vocab.js` และแคชสำหรับเปิดออฟไลน์
- หน้าเปิดครั้งแรกจะใช้คลังศัพท์ที่ฝังไว้ หากเบราว์เซอร์มีคลังเดิมจากชุดสำรองนี้ แอปจะอัปเดตคำแปลที่แก้และรวมรายการซ้ำ โดยเก็บสถานะทบทวน รายการโปรด และคำที่ผู้ใช้เพิ่มไว้
- คำ 248 คำที่เดิมขาดคำแปล (ไฟล์ `missing-translations.csv`) ได้รับคำแปลไทย/อังกฤษ/จีน/เกาหลีที่ AI ร่างให้แล้ว ติดแท็ก `แปลร่างโดย-AI` ไว้ให้กรองมาตรวจทาน เมื่อตรวจแล้วลบแท็กได้ คำทั้ง 1,026 คำที่เคยไม่มีหมวดถูกจัดหมวดแล้ว (หมวดที่ใช้คีย์เวิร์ดควรไล่ดูอีกรอบ) ช่อง CEFR ยังว่าง ตั้งเองได้ที่ปุ่ม ✎ ในคลังคำศัพท์
- ไฟล์ `polyglot-backup.json` เป็นข้อมูลสำรองฉบับเต็มที่แก้แล้ว รวมประวัติทบทวนและ metadata; นำเข้าได้จากหน้า “คลังคำศัพท์”
- เติมคำแปลเกาหลีชุดตรวจทานแรก 25 รายการแล้ว; ช่องเกาหลีเก่าที่ยังไม่มีคู่แปลอ้างอิงยังคงว่างไว้ แทนการเดาคำแปล

## ฟีเจอร์

- คลังคำศัพท์หลายภาษา, ระดับ CEFR, สถานะ, โน้ต, แท็ก, รายการโปรด และนำเข้า/ส่งออก
- ทบทวนแบบ spaced repetition (SM-2) โดยคำใหม่เข้าคิววันละ 20 คำ (ปรับ 5–100 หรือไม่จำกัดได้ที่หน้าทบทวน), แฟลชการ์ด และแบบทดสอบออฟไลน์
- เป้าหมายการทบทวนรายวัน เหรียญรางวัล 6 แบบ และปุ่มเสียงอ่านออกเสียง (ตั้งค่าในหน้า “แผนการเรียนและสถิติ”; เสียงขึ้นกับเสียงที่เบราว์เซอร์/ระบบมี)
- ใบงานคัดลายมือและสติกเกอร์จากคำศัพท์ที่บันทึกไว้
- ใบงาน: ปุ่มซ่อน/แสดงคำอ่าน คำแปล รูป หัว-ท้ายกระดาษ ช่องชื่อ/ชั้น/เลขที่/วันที่ และปุ่มซ่อนแผงตั้งค่า (ไฟล์ `worksheet-extras.js`); โหมดกิจกรรมใหม่ 6 แบบ (เติมคำในประโยค, ปรนัย, ถูก/ผิด, ฟังแล้วเขียน, ค้นหาคำ, อักษรไขว้) พร้อมหน้าเฉลย; ชื่อวิชา/ครู, ชุดข้อสอบ A–D สลับลำดับ, ความหนาเส้น, ตัวอย่างจางลง, ตั้งชื่อไฟล์, พิมพ์เฉพาะหน้าเฉลย; กรองคำตาม CEFR/สถานะก่อนส่งไปใบงาน; ส่งคำจากคลังไปใบงานพร้อมอิโมจิ (จับจากคำอังกฤษที่พบบ่อยเท่านั้น) และคำแปลอังกฤษ
- **เติมข้อมูลที่ขาด** (เมนู “จัดการคลังคำ”): คิวทีละคำสำหรับคำที่ขาดคำแปล/คำอ่าน/ระดับ/หมวด เลือกเงื่อนไขและหมวดได้ มีปุ่ม “บันทึกแล้วไปคำถัดไป” (กด Enter ได้) และโหมด **ตั้งระดับด่วน** กดปุ่ม A1–C2 หรือแป้น 1–6 แล้วข้ามไปคำถัดไปทันที ระบบไม่เดาค่าให้
- **แก้ไขหลายรายการพร้อมกัน** ในหน้าคลังคำศัพท์: ติ๊กหลายคำ (หรือ “เลือกทุกคำที่ตรงตัวกรอง”) แล้วตั้งระดับ/หมวด/สถานะ เพิ่ม-เอาแท็กออก หรือลบพร้อมกัน มีปุ่มย้อนกลับการแก้ไขล่าสุด (ย้อนได้จนกว่าจะปิดหน้า)
- **ตรวจคุณภาพข้อมูล**: รายงานคำซ้ำ (ไทย+อังกฤษตรงกัน หรือเทียบทีละภาษา) พร้อมปุ่มรวมรายการ (เก็บรายการที่เรียนไปมากที่สุด เติมช่องว่างจากรายการอื่น รวมแท็ก/ประวัติ ค่าที่ขัดกันจดไว้ในโน้ต), คำไม่มีหมวด (ตั้งหมวดทีละหลายคำ), ช่องภาษาที่ว่าง (ส่งออกเป็น CSV ได้)
- **คำอ่านญี่ปุ่นอัตโนมัติจาก JMdict**: แท็บ “คำอ่านญี่ปุ่น” ในหน้าตรวจคุณภาพ เทียบกับพจนานุกรมที่นำเข้าไว้ เสนอเฉพาะคำที่ตรงตัวอักษรทุกตัว ผู้ใช้ต้องติ๊กและกดยืนยันก่อนบันทึก (ไม่เดา) ต้องนำเข้า JMdict ที่หน้า “พจนานุกรมออฟไลน์” ก่อน — ไม่ได้แนบ JMdict มากับแอป
- **คำที่ลืมบ่อย (leech)**: รายการคำที่ “จำไม่ได้” + ตอบผิดรวมถึงเกณฑ์ (ปรับได้) พร้อมโหมดฝึกเฉพาะกลุ่มที่บันทึกลง SM-2, ติดแท็ก leech, รีเซ็ตตัวนับรายคำ
- **ทางลัดคีย์บอร์ดในหน้าทบทวน**: Space พลิกการ์ด, 1–4 ให้คะแนน (จำไม่ได้/ยาก/จำได้/ง่ายมาก), S/D ฟังเสียงคำถาม/คำตอบ
- **คำประจำวัน** บนหน้าภาพรวม สุ่มจากคำที่ยังไม่เคยทบทวน (คงเดิมทั้งวัน) สุ่มคำอื่นหรือเพิ่มเข้าคิวทบทวนวันนี้ได้
- พจนานุกรมออฟไลน์ นำเข้า JMdict JSON เพื่อบันทึกใน IndexedDB
- PWA พร้อม service worker สำหรับแคชแอปและคลังศัพท์

## ออฟไลน์

ไฟล์ของแอป ฟอนต์ และ html2canvas ถูกแคชโดย service worker ส่วนตัวอ่านไฟล์ Excel (SheetJS) และตัวสร้าง QR (qrcode-generator) ยังโหลดจาก cdnjs ตอนติดตั้ง — ควรเปิดแอปแบบออนไลน์อย่างน้อยหนึ่งครั้งก่อนใช้ออฟไลน์ ถ้าโหลดไม่ได้ การนำเข้า Excel จะแจ้งให้ใช้ CSV แทน

## ข้อมูลและสำรอง

ข้อมูลการเรียนรู้ในเบราว์เซอร์ไม่ถูกส่งออกจากเครื่องโดยอัตโนมัติ ใช้ “สำรองข้อมูล” ในคลังคำศัพท์เพื่อเก็บไฟล์ JSON เพิ่มเติม

ข้อมูลเก็บใน localStorage (เพดานราว 5 ล้านตัวอักษร) หน้า “แผนการเรียนและสถิติ” แสดงพื้นที่ที่ใช้ไป และแอปจะแจ้งเตือนถ้าบันทึกไม่สำเร็จ ประวัติทบทวนเก็บต่อคำสูงสุด 30 รายการ และตัดช่องว่าง/ค่าเริ่มต้นออกตอนบันทึก (เริ่มต้นใช้ราว 23%)

## ทดสอบ

`node tests/smoke.js` (ต้องติดตั้ง playwright) ตรวจว่าแอปเปิดได้ ไม่มี JS error และการแก้เครื่องมือ (`patchTool`) หา anchor เจอครบ

`node tests/features.js` ทดสอบฟีเจอร์เติมข้อมูล แก้หลายรายการ ตรวจคุณภาพ คำอ่านจาก JMdict leech คีย์ลัด และคำประจำวัน (ทดสอบบน localStorage ของเบราว์เซอร์ชั่วคราว ไม่กระทบข้อมูลจริง)

## หมายเหตุใบงาน

- ช่อง CEFR ของคำทุกคำยังว่าง ตัวกรอง CEFR จะมีผลหลังกำหนดระดับเอง (ใช้ “ยังไม่กำหนด” เพื่อกรองคำที่ยังไม่ตั้ง)
- คลังคำไม่มีประโยคตัวอย่าง โหมดเติมคำในประโยคจึงต้องวางประโยคเอง ไม่เช่นนั้นจะใช้คำแปลเป็นโจทย์
- ไม่มีลูกศรลำดับขีดอัตโนมัติ เพราะต้องใช้ข้อมูลลำดับขีดของอักษร (ยังใช้ช่อง “รูป” ใส่ภาพลำดับขีดเองได้)
- ช่องเลื่อนในใบงานเปลี่ยนเป็นช่องกรอกตัวเลข ขีดจำกัด: จำนวนแถว 1–30, ช่องต่อแถว 1–40, ระยะห่างแถว 0–100, ระยะห่างตัวอักษร −20–100, ขนาดตัวอักษร 8–150, ขนาดช่องสูงสุด 10–100% (ค่านอกช่วงจะถูกปรับเข้าช่วงอัตโนมัติ)
