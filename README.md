# Polyglot Studio — ชุดข้อมูลแก้ไขแล้ว

แอปเว็บแบบ static ไม่มีขั้นตอน build คลังคำศัพท์ชุดที่แก้ไขแล้วฝังมากับแอปและใช้งานออฟไลน์ได้ ส่วนตารางทบทวนและการตั้งค่าจะเก็บใน local storage ของเบราว์เซอร์

## วิธีเปิด

1. แตก ZIP ไปยังโฟลเดอร์ที่ต้องการ
2. เปิดเทอร์มินัลในโฟลเดอร์นั้น แล้วรัน `python3 -m http.server 8000` (Windows ใช้ `py -m http.server 8000`)
3. เปิด `http://localhost:8000` ในเบราว์เซอร์

ควรเปิดผ่าน local server หรือ HTTPS เพื่อให้ service worker และการติดตั้ง PWA ทำงานได้

## ข้อมูลศัพท์ที่รวมมา

- มีคำศัพท์ที่ผ่านการรวมรายการซ้ำแล้ว 4938 รายการ ฝังใน `polyglot-vocab.js` และแคชสำหรับเปิดออฟไลน์
- หน้าเปิดครั้งแรกจะใช้คลังศัพท์ที่ฝังไว้ หากเบราว์เซอร์มีคลังเดิมจากชุดสำรองนี้ แอปจะอัปเดตคำแปลที่แก้และรวมรายการซ้ำ โดยเก็บสถานะทบทวน รายการโปรด และคำที่ผู้ใช้เพิ่มไว้
- ไฟล์ `polyglot-backup.json` เป็นข้อมูลสำรองฉบับเต็มที่แก้แล้ว รวมประวัติทบทวนและ metadata; นำเข้าได้จากหน้า “คลังคำศัพท์”
- เติมคำแปลเกาหลีชุดตรวจทานแรก 25 รายการแล้ว; ช่องเกาหลีเก่าที่ยังไม่มีคู่แปลอ้างอิงยังคงว่างไว้ แทนการเดาคำแปล

## ฟีเจอร์

- คลังคำศัพท์หลายภาษา, ระดับ CEFR, สถานะ, โน้ต, แท็ก, รายการโปรด และนำเข้า/ส่งออก
- ทบทวนแบบ spaced repetition, แฟลชการ์ด และแบบทดสอบออฟไลน์
- ใบงานคัดลายมือและสติกเกอร์จากคำศัพท์ที่บันทึกไว้
- พจนานุกรมออฟไลน์ นำเข้า JMdict JSON เพื่อบันทึกใน IndexedDB
- PWA พร้อม service worker สำหรับแคชแอปและคลังศัพท์

## ข้อมูลและสำรอง

ข้อมูลการเรียนรู้ในเบราว์เซอร์ไม่ถูกส่งออกจากเครื่องโดยอัตโนมัติ ใช้ “สำรองข้อมูล” ในคลังคำศัพท์เพื่อเก็บไฟล์ JSON เพิ่มเติม
