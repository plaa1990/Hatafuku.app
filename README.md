# Polyglot Studio

แอปเว็บแบบ static ไม่มีขั้นตอน build คลังคำศัพท์และตารางทบทวนเก็บใน browser ของเครื่องที่เปิดใช้งาน ส่วนพจนานุกรมที่นำเข้าเก็บใน IndexedDB

## วิธีเปิด

1. แตก ZIP ไปยังโฟลเดอร์ที่ต้องการ
2. เปิดเทอร์มินัลในโฟลเดอร์นั้น แล้วรัน `python3 -m http.server 8000`
   - Windows ใช้ `py -m http.server 8000` ได้
3. เปิด `http://localhost:8000` ในเบราว์เซอร์

ควรเปิดผ่าน local server แทนการเปิด `index.html` โดยตรง เพื่อให้ manifest และ service worker ทำงานได้ เปิดผ่าน HTTPS หรือ localhost เพื่อให้ติดตั้งเป็น PWA ได้ บางฟอนต์โหลดจาก Google Fonts เมื่อออนไลน์ แต่การทบทวน คลังคำศัพท์ แบบทดสอบ พจนานุกรมที่เก็บไว้ และการสร้าง PDF ทำงานในเครื่องได้

## ฟีเจอร์ที่เพิ่ม

- คลังคำศัพท์: เลือกระดับ CEFR A1–C2 หรือกำหนดระดับเอง, สถานะงาน, แท็กสี, โน้ต, วันที่สร้าง/แก้ไข, กรองตามระดับ, ย้ายลำดับ และทำสำเนาคำ
- ใบงาน: สีตัวอักษร/เส้น, เทมเพลตเว้นช่อง, โลโก้และที่อยู่ซ้ำทุกหน้า, กรอบการ์ด, ช่องคะแนน, สุ่มคำ, ขอบกระดาษรายด้าน, คำแนวตั้ง และซ่อนคำชั่วคราว
- สติกเกอร์: ตัดบรรทัดอัตโนมัติ, ตัวเอียง, พรีวิวแบบแชต และชื่อ/คำอธิบาย/แท็กในไฟล์ ZIP
- มือถือ: เปิดเครื่องมือคัดลายมือและสติกเกอร์แบบเต็มจอ พร้อมจัดตัวเลือกเป็นกลุ่มพับ/ขยาย แล้วกลับสู่หน้าแอปได้ทันที
- ทบทวนคำศัพท์: ใช้อัลกอริทึม SM-2 ให้คะแนน Again / Hard / Good / Easy และคำนวณวันทบทวนถัดไป
- แบบทดสอบ: ฝึกสะกดคำ เลือกตอบ 4 ตัวเลือก และจับคู่คำศัพท์กับความหมาย โดยไม่เรียกบริการออนไลน์
- ภาษาญี่ปุ่น: เพิ่มช่องฮิรางานะ คันจิ และฟุริงานะในคลัง เลือกรูปแบบการแสดงผลและฟอนต์ฟรีในใบงาน
- พจนานุกรมออฟไลน์: มีคำศัพท์เริ่มต้น 25 รายการ และนำเข้าไฟล์ JMdict / JMdict-Simplified JSON เพื่อเก็บใน IndexedDB แล้วค้นหาโดยไม่ต่ออินเทอร์เน็ต
- สถิติและแผนเรียน: แสดงสตรีก จำนวนครั้งที่ฝึกใน 14 วัน และคำที่ตอบผิดหรือจำยากบ่อย
- ชุดคำศัพท์: นำเข้าชุดตัวอย่าง JLPT N5, JLPT N4 และภาษาญี่ปุ่นในชีวิตประจำวันได้ในคลิกเดียว (ชุด JLPT เป็นตัวอย่างขนาดย่อม ไม่ใช่รายการครบถ้วน)
- PWA: manifest และ service worker แคชไฟล์แอปหลักไว้เพื่อเปิดซ้ำแบบออฟไลน์ได้ และแคชไลบรารีจาก CDN (xlsx, qrcode) กับ Google Fonts เมื่อโหลดได้ครั้งแรกขณะออนไลน์ จึงใช้ Excel/QR/ฟอนต์ซ้ำแบบออฟไลน์ได้หลังเปิดแอปออนไลน์อย่างน้อยหนึ่งครั้ง

## ข้อมูลและสำรอง

ข้อมูลคำศัพท์ บันทึกการเรียน และการตั้งค่าอยู่ใน local storage ของเบราว์เซอร์นั้น ใช้ Export backup เพื่อเก็บ JSON; Export CSV มีข้อมูลภาษาญี่ปุ่น แท็ก การจัดตารางทบทวน และวันที่สร้าง/แก้ไข

พจนานุกรมเริ่มต้นเป็นชุดเล็กที่มากับแอป ไม่ใช่ฐานข้อมูล JMdict เต็มชุด หากต้องการเพิ่มข้อมูล ให้นำเข้าไฟล์ JMdict JSON ที่คุณมีสิทธิ์ใช้งานจากหน้า Offline dictionary; ระบบจะบันทึกไว้ใน IndexedDB ของเบราว์เซอร์นั้น ไฟล์พจนานุกรมที่นำเข้าไม่ถูกแนบมากับแอปหรือซิงก์ไปเครื่องอื่น
